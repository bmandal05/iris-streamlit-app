# 🌼 Iris Flower Species Classifier 🌿

This is a simple Streamlit web app that classifies Iris flowers into:
- Setosa
- Versicolor
- Virginica

based on input flower measurements using a trained **Random Forest Classifier**.

---

## 🚀 Features

- Built with **Streamlit**
- Trained on **Iris Dataset**
- Visualizes prediction probabilities
- Fully interactive sliders for inputs
